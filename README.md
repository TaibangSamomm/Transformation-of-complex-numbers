# Transformation of Complex Numbers

This repository is about a Python program that applies mathematical transformations to a user-inputted complex number, including **translation, scaling, rotation, and reflection**. Also, uses Matplotlib to visualise these transformations on the complex plane.

## Requirements
- Python 3
- Matplotlib

If Matplotlib is not installed, open Command Prompt (Windows) and run:

```bash
pip install matplotlib
```
## Mathematical Explanation

- **Translation:** Shifts a complex number (z) by adding a translation vector (c) The translated complex number is:
zc=z+c

- **Scaling:** Changes the magnitude of a complex number (z) using a scale factor (k). The scaled complex number is:
zk=z*k

- **Rotation:** Rotates a complex number (z) about the origin by an angle theta. The rotated complex number is:
zr=ze^(i*theta)

- **Reflection:** Reflects a complex number (z) across the real or imaginary axis using its complex conjugate, with a sign change depending on the axis of reflection.

## How to Run

- Download or copy the code from this repo and save it as a .py file (e.g., complex_transform.py).
- Open IDLE Python.
- Select File → Open and choose your Python file.
- Select Run → Run Module (or press F5) to execute the program.
